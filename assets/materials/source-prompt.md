# Silk height source

Generated with the built-in image generation tool. The PNG is an artistic scalar height field, not measured depth. The material generator derives all runtime maps from this source and repairs its tile boundaries.

Prompt:

> Use case: scientific-educational. Asset type: tileable grayscale height-map source for a music visualization material, one square texture atlas tile filling the entire image. Create an elegant shallow organic relief like flowing silk crossed with gently etched mineral ripples: broad softly curving fluid ridges, several scales of delicate continuous filament-like striations, fine restrained grain. Uniformly distributed detail with no central motif. Pure neutral grayscale only, height information with light gray raised ridges and darker shallow troughs; keep most values between 30% and 70% gray, subtle smooth depth, no pure white highlights or solid black shadows. Orthographic top-down flat texture, no perspective, no scene, no objects, no text, no labels, no watermark, no frame. All edges should tile seamlessly horizontally and vertically. No baked lighting, cast shadows, specular highlights, or ambient occlusion. This source will be used to calculate mathematically consistent normal and roughness maps and animate lighting separately.
