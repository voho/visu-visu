# Promo typography

Promo titles use **Cormorant Garamond** (weight 600); artist names use **Manrope** (weight 500). Both variable TrueType fonts are bundled so offline renders use consistent typography across systems.

Downloaded from the [Google Fonts repository](https://github.com/google/fonts) on 2026-10-02:

- [Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond) — original font, `CormorantGaramond[wght].ttf`; license in `CormorantGaramond-OFL.txt`.
- [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope) — original font, `Manrope[wght].ttf`; license in `Manrope-OFL.txt`.

Both are distributed under the SIL Open Font License 1.1. The files are unmodified; filenames omit the variable-axis brackets. The renderer registers private family aliases without changing the fonts.
