# Architecture

The main video pipeline is a deterministic batch renderer. A local WebGL visualization preview combines the flowing Resonance geometry with generated material maps and music-driven lighting. It shares musical signals and visual behavior with the batch core, while using a different mesh density and drawing path; MP4 export remains in the Canvas renderer.

## Boundaries

### 1. Decode

[`src/audio/decode.ts`](../src/audio/decode.ts) asks FFmpeg for mono, 24 kHz, 32-bit floating-point PCM. Hashing decoded PCM means container metadata does not affect the automatic visual seed.

### 2. Analyze

[`src/audio/analyze.ts`](../src/audio/analyze.ts) calculates fixed-rate feature frames. A 2048-sample Hann window feeds an in-repository radix-2 FFT. Logarithmic frequency bands and track-wide percentile normalization turn source-dependent magnitudes into stable `0..1` control signals.

The analysis stage owns signal processing and temporal smoothing. RMS attack and release coefficients account for elapsed time, preserving their response across output frame rates. Analysis defaults to 60 feature frames per second to match the 60 fps output. Analysis caches remain version **2**; older versions and caches sampled at another output frame rate must be regenerated.

[`src/audio/onsets.ts`](../src/audio/onsets.ts) extracts shared onset events from normalized analysis and queries them by absolute time. Flat or clipped peaks produce one event at their leading edge; the initial FFT comparison against silence is excluded. The conductor uses fixed-time event envelopes for rhythm activity and beat decay.

### Highlight selection and metadata

The `clip` CLI subcommand shares decoding, analysis and `renderVideo()` with ordinary renders. [`src/audio/clip.ts`](../src/audio/clip.ts) exposes the pure `selectClip(analysis, options)` API. Prefix integrals of bass-weighted energy allow time-based pre-hit, attack and post-hit windows to be scored in linear time. A candidate needs a sharp rise and sustained contrast; isolated impulses and gradual intro ramps are rejected. Context weighting favors usable lead-in and post-drop music. With no distinct drop, the highest mean-energy window wins, with deterministic earliest ties.

`ClipSelection` records source `start`, `end`, `duration`, optional `drop` and `dropOffset`, a selection `reason`, and a heuristic `score`. Default duration is 30 seconds and lead-in five seconds. Manual `drop` overrides the detector. Frame-aligned starts and durations keep normal delivery within the requested limit; short sources retain their available audio and the render core pads only a fractional final video frame. A drop near EOF shortens the clip while preserving lead-in. Selection never slices the analysis, so the visual renderer continues on the original absolute song timeline.

[`src/audio/metadata.ts`](../src/audio/metadata.ts) reads structured FFprobe tags using an argument array. Explicit CLI text and config text take priority, then format/audio-stream tags supply normalized title and artist values; album artist is a fallback. Clip export requires an artist credit. The portrait layout retains the same large credits and safe zones as full-song rendering: supplied artwork sits beside left-aligned title and artist text in a centered group, while text without artwork remains centered.

`clip --dry-run` validates the analysis/source relationship and prints the selection, delivery profile, frame-quantized duration and effective fades as JSON without starting an encoder. The clip profile defaults to native 1080×1920 at 60 fps and final encoding, with independent 0.35-second entrance and three-second exit fades. Near source boundaries, the entrance is capped at the drop offset and the exit leaves a brief full-volume post-drop hold; dry-run and encoding receive the same effective fades. Normal render defaults remain unchanged.

### 3. Plan and render

[`src/render/renderer.ts`](../src/render/renderer.ts) draws the **Resonance** preset using named seeded streams for harmonic filaments, radial nebula lobes, bokeh, stardust, depth glints, orbital ribbon and vortex plans, onset accents, and grain. Object properties are generated once or derived from an event's stable analysis-frame index. Positions are analytic functions of absolute time and integrated musical time, so frame `n` is independent of frames `0..n-1`.

[`src/render/music-motion.ts`](../src/render/music-motion.ts) exposes `deriveMusicMotion(analysis, time)`. It derives independently normalized bass, mid and treble envelopes, bass and treble transient pulses, and a sustained energy envelope. Attack and release rates use elapsed seconds. Cached scalar prefix integrals and analytic integration inside each analysis interval produce `slowTime` and `fastTime`; motion accelerates with musical energy without accumulating mutable render state or changing position abruptly. Direct seeks and sequential rendering follow the same path, and transient pulses never precede their analysis timestamps.

[`src/render/scene-dynamics.ts`](../src/render/scene-dynamics.ts) adds six independent spectral envelopes and momentum clocks through `deriveSceneDynamics(analysis, time)`. Each tier reads a fractional interval of the analyzed spectrum. A shared causal peak reference with an eight-second release and a gain ceiling of five reveals quiet passages while preserving the stronger low-frequency response; later analysis frames cannot rescale earlier tier states. An attack/release envelope drives a second momentum filter. The returned `energy` is that momentum-smoothed value, so spatial scale, light and opacity have the same inertia as motion speed. The cascade and its integrated area are evaluated analytically at each tier's delayed timestamp; cached prefix states make direct, reverse and sequential seeks agree.

| Tier | Frequency focus | Delay | Envelope release | Momentum | Typical role |
| --- | --- | --- | --- | --- | --- |
| `drift` | Deepest lows | 180 ms | 8 s | 3.2 s | Broad, slowly gathered movement and palette drift |
| `cloud` | Lows and lower mids | 140 ms | 3 s | 1.05 s | Lingering atmosphere and stardust |
| `body` | Bass | 80 ms | 0.7 s | 0.22 s | Sculpture, camera breathing and large depth motion |
| `detail` | Mids and upper mids | 40 ms | 0.3 s | 0.085 s | Faster glints and finer particles |
| `spark` | Upper spectrum | 15 ms | 0.12 s | 0.028 s | Small rapid sparks and orbiters |
| `impact` | New bass-supported hits | 25 ms | 1.2 s | 0.1 s | Local light pulses and expanding accents |

The impact tier excludes the initial FFT comparison and requires positive raw bass flux or a new onset supported by bass; normalization recovery during a held note cannot manufacture a hit. Baseline motion starts at time zero even though musical contributions are delayed. Slow tiers can continue gathering after a burst while faster tiers are already releasing. Tests check distinct latency, momentum-to-clock consistency, frame-rate independence and independence from later analysis frames. These controls complement the existing `MusicMotion` transport and conductor rather than replacing their geometry and section-level roles.

[`src/render/music-effects.ts`](../src/render/music-effects.ts) maps this motion through `deriveMusicEffects(motion, lowFlash, dynamics?)` to zoom, rotation, color phase, saturation, spatial light dispersion and glow. The renderer supplies the scene dynamics so palette travel, glow and broad deformations share the delayed responses. The legacy `hueShift` control advances through the shared palette instead of rotating source RGB hues. Its `frequencyResponse(energy, bandPosition)` gives low frequencies greater spatial influence than equal high-frequency amplitudes. Bass and kicks drive the largest deformations and camera pulses, mids influence slow rotation, and highs produce smaller rapid detail. Low-flash mode limits transient light accents while retaining expressive low-frequency movement.

[`src/render/scene-optics.ts`](../src/render/scene-optics.ts) maps the delayed tiers into the sculpture's broad music controls while retaining fine transient detail and the existing transport clocks. It also supplies a bounded camera drift, roll and breathing zoom shared by the live sculpture, its audio field and historical capture poses. Current-frame emission receives broad softening and three faint enlarged, rotated copies, followed by a finer halo. All filtering runs on the existing quarter-resolution emission surface. A final screen-space mask is applied after filtering, keeping the sharp sculpture and credits clear.

[`src/render/resonance.ts`](../src/render/resonance.ts) builds 72 flowing filaments with 241 points each, including the repeated closing point. The slow musical clock changes the aperture and tube proportions from an open ring toward an orb, introduces a three-lobed radial contour and bends the volume into a plasma knot. Opposing horizontal/vertical stretch and broad 3D precession change its silhouette as it turns through perspective. Normalized bass energy and causal bass transients drive the largest broad folds; mids have a smaller influence on tube shape and flow; treble energy and pulses add fine ripples on the fast clock. Frequency-weighted spectral bands and low waveform harmonics supply further detail. Strand-dependent displacement is periodic in its poloidal angle, so the last and first mesh rows join without a spectrum-driven seam. The projected sculpture is fitted as a whole after accounting for the exact scene camera. A smooth bounded enlargement brings compact poses closer while reserving clipping clearance for large folds; one scalar preserves the existing X:Y projection ratio. Live geometry, frozen captures, background influence and the short contour echo all pass their drawing camera into this fit. Point depth separates front and back drawing passes. Fast tracers follow its contours; local energy controls their brightness. Sustained musical time and frequency energy move the field through its shared source palette, with neutral highlights and bounded saturation changes. A sparse 18-strand contour echo sampled 180 ms earlier adds decaying trails without retaining a previous framebuffer or rebuilding the full dense mesh.

[`src/render/frozen-cloud.ts`](../src/render/frozen-cloud.ts) plans sparse, bass-weighted sculpture captures with at least three seconds between events, a 7.5-second lifetime and at most three live ghosts. Each event fixes the sculpture's geometry, textured skin, spectrum lighting, camera and colors at its capture timestamp. [`src/render/frozen-cloud-layer.ts`](../src/render/frozen-cloud-layer.ts) renders a small snapshot surface from that timestamp and caches it by source analysis and event identity; it is not sampled from whichever frame happened to render previously. Absolute event age drives a perspective expansion from 1 to about 2.22 as the ghost approaches the viewer. Opacity rises gently over 0.6 seconds to at most 0.20, then decays; stronger blur and fixed-mask erosion develop after 1.1 seconds, allowing the original object to remain recognizable before becoming fog. Blur reaches 22% of the hero radius near expiry. The ghosts are composited behind the live sculpture, with the credit mask applied after expansion and softening. Forward, reverse and direct seeks recreate the same frozen material, impression and fade, including after cache eviction.

[`src/render/artwork.ts`](../src/render/artwork.ts) prepares a local PNG, JPEG, WebP or AVIF image once, before the encoder opens. `--image` overrides `visual.imagePath`; a relative CLI path resolves from the working directory, while a relative config path resolves beside its JSON file. Empty `imagePath` leaves the procedural scene unchanged. SVG, URLs and data URLs are not accepted.

The preparation stage downsamples to at most 512 pixels on its long edge, gently blurs, and compresses contrast while retaining recognizable cover detail and color. The hero mask retains at least 40% of image opacity before the other fades so artwork remains visible around the material sculpture. Artwork receives no full-width credit darkening: broad shadows cast by the actual title and artist glyphs provide local contrast instead. A separate feathered vignette reduces image alpha by up to 58% toward the corners, independently of the scene's final vignette. The renderer consumes the prepared surface and palette through `PreparedArtwork`, keeping image loading and processing outside the per-frame drawing loop. The source image is never modified.

[`src/render/palette.ts`](../src/render/palette.ts) defines a shared `ScenePalette` for the complete scene. Artwork colors are extracted from the full image before any aspect-ratio crop, ignoring transparent pixels. Interpolation, neutral highlights, desaturation and brightness changes preserve those source color families; a grayscale source remains grayscale. The renderer applies the palette to material color, ambient and point lights, reflected spectrum light, filaments, transient effects, particles, clouds, shadows and the subtle credit tint. Musical phase selects and mixes palette colors instead of introducing independent hue rotations. Without artwork, the visual seed creates a reproducible varied palette. Frame-level tests exercise monochrome and single-hue artwork during strong transients and overlapping ghosts, checking for unrelated color leakage across the completed image.

The pure `deriveArtworkMotion(time, music)` API computes image scale, saturation and opacity; its compatibility `hueShift` field stays zero. Scale combines slow musical breathing at `1.018 ± 0.009` with an additive bass-pulse zoom of at most `0.012`. Normalized bass, mid and treble energy contribute 4.5%, 3% and 1.5% respectively to saturation, capped together at a 9% boost. Opacity ranges from 0.72 to 0.81 with sustained energy and does not flash on beat impulses. These transforms preserve source hues and derive directly from absolute musical time and envelopes, so repeated seeks agree.

[`src/render/artwork-influence.ts`](../src/render/artwork-influence.ts) gives the background a gentle wake from actual past sculpture geometry. It combines poses delayed by 350, 700 and 1,150 ms with weights of 50%, 32% and 18%. Each pose interpolates adjacent 10 Hz captures, all safely behind the current song timestamp; startup uses the initial pose. A 32-entry cache is scoped to the analysis object and reconstructs evicted samples by absolute capture time, so arbitrary seeking reproduces the same field.

[`src/render/artwork-warp.ts`](../src/render/artwork-warp.ts) turns stable strand/point landmarks, their tangents and depth into a smooth local displacement field. `sceneCameraMatrix` projects these landmarks with the same camera as the visible sculpture. Blending corresponding landmarks retains the changing shape rather than substituting an independent radial pulse. A 33 × 33 field grid bounds displacement to 0.6% of the shorter output edge, at most 6.48 pixels for Full HD. Screen-space protection holds the credit region and image edges fixed against displacement even while the cover zooms. `ArtworkWarp` resamples its immutable prepared cover with alpha-weighted bilinear interpolation, preserving source color families and preventing hidden transparent RGB from bleeding into the image. The separately shaded cover relief receives the identical field and zoom, keeping highlights registered to the bent cover. The object's photograph remains independent of this background effect.

### Materials and moving lights

[`src/render/material.ts`](../src/render/material.ts) owns coherent albedo, scalar height, unit tangent-space normals and roughness. [`scripts/generate-materials.ts`](../scripts/generate-materials.ts) processes the committed AI grayscale relief source, feathering its boundary into a deterministic periodic harmonic field. It exports four matching 512² PNG maps and an area-averaged 128² byte array in [`assets/materials/silk-height.ts`](../assets/materials/silk-height.ts). Normal vectors come from central height gradients with wrapped neighbors: +X is right, +Y is up and +Z points toward the viewer. RGB normal files encode each signed component as `component × 0.5 + 0.5`. Roughness and normal files are linear data textures.

`createMaterial(seed, size)` imports the packed source synchronously, uses a seed-stable periodic offset, and derives CPU maps once. `recolorMaterial(material, palette)` replaces its decorative albedo with source-palette pigment while preserving the height, normal and roughness maps. Runtime dimensions are bounded to 256², with 128² as the default; the generator accepts up to 2048² for exported assets. `createProceduralHeight` remains available as a deterministic source-independent fallback. `sampleMaterial` bilinearly samples repeating maps and renormalizes interpolated normals, accepting a reusable result object for the hot path. Matching source bytes, seed and dimensions produce matching maps; regeneration tests compare every exported file byte-for-byte.

Artwork preparation also creates an optional material from the downsampled source cover. `createMaterialFromRgba` blurs alpha-weighted luminance before deriving a weaker relief, preserves RGBA, uses higher roughness, and clamps image edges instead of repeating. This is an artistic interpretation of brightness, not inferred physical depth. Hero attenuation and the feathered vignette carry over to the prepared material. The separately shaded light layer still suppresses emission around the credits without darkening the underlying artwork.

`PreparedArtwork.objectMaterial` separately retains the full source image at up to 256 pixels on its long edge, without the background crop, dimming, hero attenuation or vignette. Its actual RGB and alpha map onto the folded sculpture. The artwork material tag preserves photographic pigment during lighting instead of reducing it to scalar reflectance; palette-derived light provides highlights around a neutral diffuse contribution. The same object material is used for immutable ghost captures. Procedural material atmosphere remains independent, so the photograph changes the object itself rather than a full-screen lighting texture. Integration tests exchange equal-luminance colors in images with the same palette, flatten their relief and remove the background; chromatic differences on the rendered sculpture then establish that spatial image pigment survives the complete pipeline.

[`src/render/lighting.ts`](../src/render/lighting.ts) exposes `lightingAt(motion, time, seed, paletteHue, lowFlash, spectrum?, palette?)` and `shadeSurface(state, x, y, z, sample, out?)`. Absolute slow musical time moves the bass key and midrange fill; the fast clock moves a smaller treble rim. Bass contributes the strongest energy and pulse response. The palette supplies ambient and light colors, while the phase control changes their mixture within that palette. Low-flash mode attenuates pulse intensity without changing light paths, ambient exposure or event timing. Each point light has bounded intensity, color and distance falloff. Shading combines diffuse light with roughness-dependent Blinn specular, Schlick Fresnel and restrained rim light, then applies a bounded Reinhard tone map.

The optional FFT input adds a 32-sample colored environment-light strip. Fractional area averaging supplies its bands; bass bands spread over a wider region with stronger radiance, while treble stays narrow. Every shaded surface reflects its view direction around the perturbed normal to select a strip frequency. Three filtered samples broaden the reflection according to roughness, with a Fresnel contribution at grazing angles. Strip rotation is prepared once per frame, zero spectrum contributes no light, and low-flash mode reduces its strength. The same light state reaches the material atmosphere, prepared artwork relief, filled sculpture skin and filament segments.

[`src/render/surface-signal.ts`](../src/render/surface-signal.ts) produces shared, bounded 32-bin spectrum and 32-bin signed waveform signals through fractional area averaging. The offline material and browser visualization read these same analysis features. The spectrum shapes material relief and roughness with greater low-frequency weight; the oscilloscope changes normals and bends a reflected light ribbon across the curved surface. These responses belong to the material itself rather than a separate flat chart overlay.

[`src/render/audio-field.ts`](../src/render/audio-field.ts) adds explicit spectrum and amplitude visualization around the object. A causal profile filters RMS into a fast 20 ms attack / 200 ms release envelope and a slower 280 ms attack / 1.2 s release envelope. Each of 32 frequency bands has a 32 ms attack followed by a 22 ms inertia filter, which eases velocity through FFT changes; release varies from 400 ms for bass to 120 ms for treble. [`src/render/audio-field-geometry.js`](../src/render/audio-field-geometry.js) shares the normalized geometry with the browser: 64 mirrored spectrum stems, two loudness ellipses and a signed waveform arc along the lower orbit. A narrow adjacent-band blend preserves total band energy and isolated peak locations, while monotone cubic waveform interpolation rounds contours without overshoot or losing signed sample values. Waveform ends taper to an exact zero offset. Strokes are approximately twice their previous width, with round caps and joins; lower frequencies retain larger stem extensions. Back and front passes integrate the field with the sculpture, using the same camera and palette inside the protected graph rectangle. The wider and taller orbit leaves room around the closer-framed object. Envelopes are evaluated analytically from absolute time and prior audio, so frame rates and arbitrary seeks follow the same response without borrowing future samples.

[`src/render/surface-mesh.ts`](../src/render/surface-mesh.ts) connects the same Resonance points into a material skin beneath the bright filaments. Procedural silk samples every second strand and every third curve point for 36 × 80 shared-vertex quads; a photograph uses 72 × 120 quads to retain image detail. Faces are sorted by mean camera depth, and source alpha controls their opacity. Material normals, local spectral energy and waveform slopes shade those faces; curved spectrum and waveform reflections use the moving light colors. The mesh preserves the sculpture's morphing shape and graph bounds, keeping material and filament motion aligned.

[`src/render/material-layer.ts`](../src/render/material-layer.ts) maintains a low-resolution material atmosphere, capped at 192 pixels on its long edge, which is shaded every frame and composited behind text and the live sculpture. [`src/render/surface-material.ts`](../src/render/surface-material.ts) gives filament segments a tangent basis derived from the actual camera-space geometry: the sampled tangent normal is transformed into that basis before evaluating the same lights. This makes highlights follow surface orientation instead of acting as a uniform color filter. `visual.lighting` and CLI `--lighting` set the contribution from 0 to 1, defaulting to 0.65; zero skips material lighting. The title and artist are drawn afterward and do not receive surface shading.

[`src/render/scene-atmosphere.ts`](../src/render/scene-atmosphere.ts) adds a seeded, inexpensive Canvas atmosphere: ten soft cloud plans with rotating asymmetric wisps, four curved light curtains, one palette-tinted contact shadow, three broad expanding bass rings, three rotating local diffraction streaks and 160 depth particles split across drift/body/detail/spark tiers. Cloud opacity, scale, flow and palette blending follow the slower responses. The four curtains curl along the outer thirds on the cloud and drift clocks; bass controls their bend and width, and both ends fade gently. Bass rings expand to 2.37 hero radii with a broad halo, while local diffraction rays extend farther around each hit. Lower-frequency particles have broader travel and larger size, while upper tiers are finer and faster. Each particle moves toward the viewer, growing with perspective into larger, softer near bokeh with faint rims. The near-field size increase is strongest for drift and bass particles; upper-frequency detail stays smaller. Curved trails use analytic offset-clock samples and cannot cross a flight reset; entrance and exit fades hide the reset itself. Complementary depth fades split particles behind and in front of the live sculpture. Every layer derives its pose from absolute clocks, with no accumulated particles or framebuffer history. A final-canvas clip below the credit region protects both passes even when a caller has a camera transform; low-flash mode reduces local flare and pulse intensity while retaining the slow clouds and particle paths.

The existing stardust now follows the cloud clock, depth glints follow the detail clock, and fast orbiters follow the spark clock. Material lighting and frequency reflections continue to use the same normalized music state as the sculpture. These separate responses add depth without making all visual elements accelerate and decay together.

[`src/render/supernova.ts`](../src/render/supernova.ts) exposes `novaEventsAt(analysis, time, seed, lowFlash)`. A plan cached per analysis detects positive bass and high-frequency changes against the preceding frame, with track-relative transient sensitivity and an absolute noise floor. It skips the initial FFT and never exposes an event before its timestamp. Bass events produce stronger, larger supernovas with a 0.75-second refractory period; smaller flares have a 0.3-second refractory period. Scheduling allows at most four live events and reserves a voice for bass, preserving an existing afterglow until it expires instead of truncating live tails.

Each event returns its stable analysis-frame ID, age, strength, seeded hue/angle/origin, expanding radius and separate flash, flare and afterglow envelopes. Normal flash attacks take 30–45 ms and decay over 120–160 ms; diffraction flares decay over 400–520 ms. Nova afterglow decays over 1.4 seconds, with a smooth final fade before the 2.4-second lifetime ends; small flares end after 1.1 seconds. Strong bass shockfronts approach 2.5 hero radii. The Canvas renderer turns these controls into local kick light, diffraction streaks, outward particles and expanding shockfronts. These accents remain local to their source. Low-flash mode lowers the three light envelopes and lengthens the fast attack/decay, preserving every event's identity, strength, origin, radius and motion. No previous framebuffer or accumulated particle state is needed, so direct, reverse and sequential seeks agree.

[`src/render/reactive-effects.ts`](../src/render/reactive-effects.ts) owns the pure geometry and control math for the faint orbital ribbon echoes, perspective vortex rings, travelling glint poses, and dynamic color grade. Keeping geometry outside Canvas drawing makes bounds, spectrum and waveform response, depth ordering, speed limits, low-flash behavior, and determinism directly testable without brittle pixel snapshots.

[`src/render/conductor.ts`](../src/render/conductor.ts) builds a cached, track-relative energy profile and turns local contrast, rhythm activity, build/drop trend, and beat impulses into continuous ambient, drive, peak, form, and motion controls. It uses bounded analysis windows, including deterministic look-ahead, rather than mutable playback state. A pure choreography map crossfades atmosphere, rings, ribbon, grade, glints, detail and camera across musical sections; low-flash mode caps only fast transient controls.

[`src/render/layout.ts`](../src/render/layout.ts) computes conservative landscape, square, and portrait safe rectangles. Full-bleed atmosphere ignores these bounds. Credits use a symmetric safe rectangle centered at the full frame's `width / 2`, independently of the graph center. With artwork, the rounded thumbnail and left-aligned text form one horizontally centered group; their vertical centers align. Without artwork, each text line remains centered. Portrait and square graph profiles reserve additional bottom and right space for social-player captions, controls, and action rails.

Long title and artist strings are measured and uniformly reduced to fit the available width after allowing for the thumbnail and gap, within that symmetric safe region.

### Live visualization preview

This gives the sculpture more screen space while easing framing changes around larger folds; historical captures use the same guide. [`src/preview/lighting-glow.js`](../src/preview/lighting-glow.js) captures fresh sculpture emission into a quarter-size texture, capped at 512 pixels on its long edge; a 13-tap radial filter, gentle enlargement and rotation add soft light around the current contours. [`src/preview/lighting-particles.js`](../src/preview/lighting-particles.js) draws 160 seeded GPU points across four independent clocks. Forward perspective travel grows them into larger near bokeh with brighter soft rims and fine streak accents, with separate back/front passes and invisible flight resets. Glow and particles use source-palette colors and a final screen-space credit fade. These layers are rebuilt from time and signals rather than accumulated framebuffers.

The uniform timeline also carries the two RMS envelopes and 32 filtered frequency bands from `audioFieldAt`. [`src/preview/lighting-audio-field.js`](../src/preview/lighting-audio-field.js) draws the shared spectrum stems, amplitude ellipses and waveform orbit with thicker antialiased strokes: round-ended spectrum stems and continuous ribbons for the smooth joined curves. Back and front passes surround the sculpture, with a final screen-space fade protecting the credit region.

[`src/preview/lighting-ghosts.js`](../src/preview/lighting-ghosts.js) captures the entire illuminated GPU sculpture into immutable RGBA textures at the same bass accents as the offline renderer. Historical timeline uniforms and feature textures are restored for each capture, then replaced with the current signals before drawing the live scene. The server supplies the shared capture plan and a 30 Hz sampling of its optical envelope, so both renderers use the same lifetime, perspective approach, fade and erosion timing. At most three reduced-resolution textures are cached; seeking or resizing reconstructs missing captures from their original timestamps. Fixed spatial noise, a weighted 17-sample spiral blur and screen blending turn the preserved object into mist, with a screen-space mask protecting credits after expansion. Material inspection modes omit ghosts so the surface maps remain clear.

The server binds only to `127.0.0.1` and serves explicit whitelisted routes for its UI, timeline, selected song, optional artwork and material maps. HTTP byte-range support allows audio seeking; arbitrary filesystem paths are never derived from requests. `--image`, `--title`, `--artist`, `--seed`, `--port` and `--low-flash` configure the preview. WebGL runs at browser refresh cadence and reports measured frame rate. The GPU mesh differs from the offline 72 × 240 sculpture and does not reproduce every Canvas layer. It provides no MP4 export path or promise of pixel parity; `render` and `clip` remain the delivery commands.

### 4. Encode

[`src/render/encoder.ts`](../src/render/encoder.ts) streams raw RGBA frames to FFmpeg with backpressure. FFmpeg applies the Lanczos delivery filter (a spatial resize only when internal and delivery dimensions differ), synchronized picture-to-black and audio-to-silence fades, then encodes H.264 High-profile video with BT.709 metadata, two B-frames, four references, and a fixed closed GOP. It seeks the original source audio to the same start time, resets its local timestamp, pads and trims it to the frame-quantized video duration, encodes stereo AAC-LC at 48 kHz with a 384 kbps target, and muxes an MP4 with fast-start metadata.

Audio is converted to a platform-oriented delivery profile: AAC-LC, stereo, 48 kHz, and 384 kbps. This conversion does not apply loudness normalization. The source audio is always mapped explicitly. Integration tests decode finished picture and PCM data to verify the full three-second fade slopes, black endpoints, silent endpoints, excerpt-local timing, and non-silent midpoint in addition to codec metadata. Additional native Full HD60 landscape and portrait tests count and decode every distinct input frame, check A/V duration within 2 ms, confirm H.264 High/yuv420p/BT.709 and AAC, and verify bitrate settings and faststart in the output file.

The longer clip E2E drives the public CLI with a synthetic song containing a known drop and a busy cover PNG passed through `--image`. It validates the selected lead-in and 30-second portrait export, then decodes a 360-pixel-wide frame to distinguish the colorful cover thumbnail from text ink, check readable title and artist lines, and verify that the combined credit group is centered. Artist-only ink samples keep picture-fade measurements independent of the cover. Cadence, A/V timing and source alignment, codecs, metadata and synchronized fades are also checked on the finished MP4.

The optional `RenderRequest.fadeInSeconds` and `fadeOutSeconds` override the two fades independently. Explicit fades are fitted proportionally when their sum exceeds the excerpt duration, so they never overlap. Without overrides the existing symmetric fade and half-duration cap apply. Timing and fades are validated before encoder creation; nonfinite start/duration values are rejected. `validateRenderAnalysis()` shares version, source-hash, band-count and frame-rate validation between encoding and CLI dry runs.

Requested durations are converted to a whole frame count once, before rendering and encoding. The reported duration, FFmpeg limit, and video frame count therefore share one value. Source-file hash verification lives in the render core, so library callers receive the same cache/audio mismatch protection as the CLI.

The default frame rate is 60 fps. Default and `final` renders work at 100% of the requested width and height, CRF 18 and the `fast` H.264 preset. A default Full HD job draws natively at `1920×1080`; the portrait equivalent is `1080×1920`. The optional `output.maxBitrateMbps` config field defaults to `16` and sets FFmpeg `-maxrate 16M -bufsize 32M`: a 16 Mbps video ceiling with a 32 Mbit buffer. Values from 0 to 200 are accepted; zero disables the ceiling. Actual average bitrate depends on visual complexity.

`--quality preview` selects half scale, CRF 22, `veryfast`, and an 8 Mbps ceiling with a 16 Mbit buffer. `--quality master` selects native scale, CRF 8, `slow`, and uncapped CRF encoding for an optional archive. All quality modes retain the configured frame rate; explicit `--fps` and `--render-scale` overrides take precedence. Omit `--quality` to retain custom encoding settings from the project config.

The upload choices follow [YouTube's recommended MP4/H.264/AAC settings](https://support.google.com/youtube/answer/1722171). Its 1080p high-frame-rate reference is 12 Mbps; this project's 16 Mbps ceiling allows additional headroom and is not a platform requirement. The Full HD60 portrait profile also fits [TikTok's media transfer specifications](https://developers.tiktok.com/docs/en/content-posting-api-media-transfer-guide): MP4/H.264, 23–60 fps, and dimensions from 360 to 4096 pixels.

## Reproducibility contract

A render plan is identified by:

- decoded PCM hash;
- input artwork bytes, when supplied;
- bundled material source bytes;
- explicit or automatically derived seed;
- analysis and renderer versions;
- output dimensions and frame rate;
- project visual settings;
- absolute frame time.

The current renderer version is **20** and analysis version remains **2**. Composition and motion are reproducible, including palette extraction or seeded palette generation, frozen-cloud capture selection, prepared background and object artwork, delayed sculpture-driven cover displacement, material placement, spectrum/amplitude envelopes and absolute-time light positions. Pixel-identical output is guaranteed within the same pinned native runtime; fonts and codecs may vary slightly across platforms until the project bundles a font and containerizes the render toolchain.
